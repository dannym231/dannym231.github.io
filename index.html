AgentCred

v0.2.1

The substrate

SDK giving AI agents a portable identity, wallet, and reputation that follows them between applications. The core is stdlib-only with zero runtime dependencies — CI runs a dedicated no-extras job that enforces this — and chain access lives behind an optional [cdp] extra.

AgentMarket

v1.1.0

Agents cooperating

Marketplace where AI agents post jobs, hire each other, and settle through escrow. Reputation gates hiring — bad history means rejection or posting collateral. Runs on simulated credits by default, or real testnet ETH on Base Sepolia via the same code path, with a Streamlit dashboard showing conservation checks and Basescan links.

AgentExchange

v1.0.1

Agents competing — the structural contrast

Where AgentMarket has agents cooperating, AgentExchange has them competing on the same substrate: four AI trader personalities (Momentum, Contrarian, Conservative, Degen) predict short-term ETH moves on live CoinGecko data, stake credits, and settle zero-sum. Frozen — it made its point.

Architecture: both economies import AgentCred, pinned at v0.2.1 — AgentMarket with the [cdp] extra, AgentExchange with the stdlib core only. “Two economies on one substrate” is literally true in the dependency graph.

On-Chain Proof

Six real Base Sepolia transactions covering both settlement paths — release and refund — each verifiable on Basescan:

Phase 2
funded 0x1a9e…9272 released 0x2983…fa21 funded 0x1820…445b refunded 0x0e8b…4a0f
Phase 5
funded 0xce4a…b10a released 0x25f7…9d1a

Conservation is checked at two layers: exact at the ledger, which must balance to zero and is asserted every run, and gas-tolerant on-chain, where the tolerance covers fees only.

Known limitations, by design: escrow is custodial — a platform-held CDP wallet rather than a smart contract, with non-custodial contract-based escrow as the named upgrade path — and everything runs on testnet, capped at 0.0001 ETH per transaction.

Stroke Outcomes & Agentic-Pipeline Evaluation

A summer research internship at a university medical school lab: a pre-registered 52-hypothesis program testing whether brain imaging predicts stroke recovery beyond clinical variables, then a 50-run evaluation of the lab's published agentic LLM analysis pipeline. The evaluation's headline: runs that computed the right statistic got the right label only 21.4% of the time — and upgrading the model made labels worse — a study of evaluation design, not a replication.
